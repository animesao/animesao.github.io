# Пользовательские ассеты: Аватар и Логотип / Custom Branding Assets

В эту папку помещаются ваши графические файлы:

## 1. Аватарка (Фото / Персонаж / Символ)
- **Имя файла:** `avatar.png` (также поддерживается `avatar.svg` или `avatar.jpg`)
- **Рекомендуемый размер:** 256x256 или 512x512 пикселей (квадратный формат).
- **Отображение:** Главный экран (Hero), страница «О себе» (About) и шапка.
- **Поведение по умолчанию:** Если файл отсутствует, сайт автоматически отображает сдержанный геометрический sci-fi аватар с монограммой `ANIMESAO`.

## 2. Логотип
- **Имя файла:** `logo.png` (также поддерживается `logo.svg`)
- **Рекомендуемый размер:** высота 32-48 пикселей с прозрачным фоном.
- **Отображение:** Шапка сайта (Header), подвал (Footer).
- **Поведение по умолчанию:** Если файл отсутствует, сайт автоматически отображает фирменный типографический знак `ANIMESAO // DEV`.
